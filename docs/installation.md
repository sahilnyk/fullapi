# Installation

## Requirements

- Python 3.8 or higher
- pip (Python package installer)

## Install from PyPI

The recommended way to install fullapi:

```bash
pip install fullapi
```

This installs the latest stable release.

## Install from Source

For development or if you want the latest changes:

```bash
git clone https://github.com/sahilnyk/fullapi.git
cd fullapi
pip install -e .
```

The `-e` flag installs in editable mode, meaning changes you make to the code are immediately available without reinstallation.

## Verify Installation

Check that fullapi is installed correctly:

```bash
fullapi --version
```

You should see the version number displayed.

## Upgrade

To upgrade to the latest version:

```bash
pip install --upgrade fullapi
```

## Uninstall

To remove fullapi:

```bash
pip uninstall fullapi
```
